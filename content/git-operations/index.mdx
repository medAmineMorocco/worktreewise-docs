## Git Operations

WorktreeWise also provides built-in Git tools to explore and compare your repository.

In this section, you’ll learn how to:

- Use **Git Log** to browse commit history in a clear, structured way.
- Use **Git Diff** to compare changes between worktrees, branches, tags, or commits.

These Git operations give you better visibility into your project history and differences, without leaving WorktreeWise.
