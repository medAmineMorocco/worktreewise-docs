# Git Operations in WorktreeWise

WorktreeWise makes it easy to perform common Git operations like viewing logs and comparing diffs across your worktrees. Streamline your workflow and manage your Git history and changes with ease.

## What You Can Do

With WorktreeWise, you can:

<p>✅ **View Git Logs** – Access the complete commit history for your worktrees</p>
✅ **Compare Git Diffs** – Compare the differences between branches, commits, or worktrees  
✅ **Seamless Integration** – Run Git operations directly within the WorktreeWise interface
