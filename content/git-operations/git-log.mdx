# Git Log in WorktreeWise

WorktreeWise provides an easy way to view the Git log of your worktrees, allowing you to inspect commit history efficiently.

## How to View Git Log

### Method 1: View Git Log for a Worktree

1. Open WorktreeWise.
2. Navigate to the **Worktrees** section.
3. Select a worktree from the list.
4. Click on the **Git Log** button.
5. A commit history view will appear, displaying:
- Commit messages
- Authors
- Timestamps
- Associated branches/tags

### Method 2: Filter Git Log

1. Open the Git Log view.
2. Use the **search bar** to filter commits by author, message, or commit hash.
3. Select a specific branch or tag to view its commit history.

<Callout type="info">Ensure your repository is synchronized with remote branches to get the latest commit history.</Callout>
