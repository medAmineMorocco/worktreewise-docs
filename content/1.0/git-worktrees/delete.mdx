## Delete a Git Worktree

To delete a worktree:

1. Navigate to the **Worktrees** section.
2. Locate the worktree you want to delete.
3. Click the **Delete** button.
4. Choose one of the following options:
- **Delete Only Worktree** (keeps the branch)
- **Delete Worktree and Branch** (removes both)

![Delete Worktree](/images/content/git-worktrees/delete/delete-worktree.png)

<Callout type="warning">Deleting a worktree and its branch is irreversible.</Callout>
