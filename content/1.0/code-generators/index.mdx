# Code Generators

This section introduces **code generators** in WorktreeWise, a feature to quickly scaffold files inside your worktrees.

Here you’ll learn how to:

- **Create new generators** with customizable parameters (`input`, `select`, `confirm`, `multiselect`).
- **Import existing generators** from other repositories.
- **Play generators** by filling parameters and selecting a target worktree.
- **Edit or duplicate generators** to adapt them to different scenarios.

Code generators help you stay consistent and productive by automating repetitive file creation tasks.
