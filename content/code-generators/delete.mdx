## Delete a Code Generator


To remove a code generator:

1. Go to the **Generators** section.
2. Locate the generator you want to delete.
3. Click the **Delete** button and confirm the deletion.

![Delete a Code Generator](/images/content/code-generators/delete-generator/delete-generator.png)

<Callout type="warning">Deleting a code generator is irreversible. Ensure you no longer need it before confirming.</Callout>
