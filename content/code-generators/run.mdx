# Run a Code Generator

To execute a code generator:

1. Go to the **Code Generators** section.
2. Select the generator you want to run.
3. Fill in the required parameters in the sidebar.
4. Choose the target worktree where the files will be generated.
5. Click the **"Run Generator"** button.

<Callout type="info">Ensure all required parameters are provided before running the generator.</Callout>
