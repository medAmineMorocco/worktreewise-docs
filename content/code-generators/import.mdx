## Import a Code Generator


To import an existing code generator from another repository:

1. Navigate to the **Generators** section.
2. Click on the **Import Generator** button.
3. Select the repository containing the generators.
4. Choose the generators to import.
5. Click **Import** to add them into the current repository.
