# Settings

Configure global and repository-specific preferences for worktree directories, external editor integrations, terminal-based AI coding agents, shell environments, Git binary paths, and character encoding.

To open Settings:
- Select **File → Settings** from the application menu.
- Or press the global keyboard shortcut **Shift + S**.

Settings are automatically persisted to local configuration and applied across all repository tabs.

## Worktrees Settings

The **Worktrees** tab configures the default parent directory and automated directory naming convention for newly created worktrees.

![Worktree settings](/images/releases/1.1.0/30-settings-worktrees.png)

### Naming Patterns

WorktreeWise generates folder names automatically using a configurable naming pattern. This standardizes folder structure across projects and teams.

#### Supported Placeholders

| Placeholder | Description | Example Replacement |
| :--- | :--- | :--- |
| `{repo}` | Name of the primary repository | `my-project` |
| `{branch}` | Sanitized branch or tag name | `feature-auth` |

#### Built-in Pattern Presets

| Pattern | Output Folder Example | Best Used For |
| :--- | :--- | :--- |
| **`{repo}__wt__{branch}`** *(Default)* | `my-project__wt__feature-auth` | Clear visual separation between repository name, worktree marker (`wt`), and branch. |
| **`{repo}__{branch}`** | `my-project__feature-auth` | Shorter directory paths. |
| **`{repo}-wt-{branch}`** | `my-project-wt-feature-auth` | Single-hyphen naming conventions. |
| **`wt__{repo}__{branch}`** | `wt__my-project__feature-auth` | Groups all worktrees together alphabetically in the parent folder. |

### Add a Custom Naming Pattern

1. In **Settings → Worktrees**, click the pattern dropdown.
2. Enter your custom pattern in the input box (for example, `worktrees/{branch}` or `wt-{repo}-{branch}`).
3. Select the **+** (Add) button.
4. The custom pattern is saved and ready for selection.
5. To remove a custom pattern, hover over it in the list and select the red trash icon.

## Editors Settings

The **Editors** tab configures external IDEs and code editors so you can launch any worktree with a single click.

![Editor settings](/images/releases/1.1.0/31-settings-editors.png)

### Supported Editors

WorktreeWise detects and integrates with standard development environments:

- **VS Code Family**: Visual Studio Code, Cursor, Windsurf, VSCodium.
- **JetBrains Family**: WebStorm, IntelliJ IDEA, Rider, PyCharm, CLion, PhpStorm, RubyMine, GoLand, Android Studio.
- **Modern Text Editors**: Zed, Sublime Text, Brackets.

### Scan for Installed Editors

Select **Scan** in the top-right corner to run automatic detection (`editors:detect-all`). WorktreeWise scans standard system paths, user application directories, and your system `PATH`:

- Detected editors display a green **Found** badge and version number.
- Newly detected editors are enabled automatically.

### Enable or Disable Editors

- Select any editor card to toggle its active state.
- Enabled editors display a highlighted blue border and appear in the **Open in** menu in the Worktree list.
- Disabled editors are hidden from action menus to keep the interface focused.

### Configure Custom Executable Paths

If an editor is installed in a non-standard location or portable directory:

1. Select the **Pencil icon (✏️)** on the editor card.
2. Enter the absolute path to the editor executable.
3. Select **Edit** to save.

#### Standard Executable Paths by Operating System

| Editor | Windows | macOS | Linux |
| :--- | :--- | :--- | :--- |
| **VS Code** | `C:\Program Files\Microsoft VS Code\bin\code.cmd` | `/Applications/Visual Studio Code.app/Contents/Resources/app/bin/code` | `/usr/share/code/code` |
| **Cursor** | `C:\Users\%USERNAME%\AppData\Local\Programs\cursor\resources\app\bin\cursor.cmd` | `/Applications/Cursor.app/Contents/Resources/app/bin/cursor` | `/usr/bin/cursor` |
| **Windsurf** | `C:\Users\%USERNAME%\AppData\Local\Programs\windsurf\bin\windsurf.cmd` | `/Applications/Windsurf.app/Contents/Resources/app/bin/windsurf` | `/usr/bin/windsurf` |
| **WebStorm** | `C:\Program Files\JetBrains\WebStorm\bin\webstorm.bat` | `/Applications/WebStorm.app/Contents/MacOS/webstorm` | `/opt/webstorm/bin/webstorm` |
| **IntelliJ IDEA** | `C:\Program Files\JetBrains\IntelliJ IDEA\bin\idea64.exe` | `/Applications/IntelliJ IDEA.app/Contents/MacOS/idea` | `/opt/idea/bin/idea.sh` |
| **Sublime Text** | `C:\Program Files\Sublime Text\subl.exe` | `/Applications/Sublime Text.app/Contents/SharedSupport/bin/subl` | `/usr/bin/subl` |

## AI Agents Settings

The **AI Agents** tab enables and configures terminal-based AI coding assistants that run directly inside worktree-scoped panes.

![AI-agent settings](/images/releases/1.1.0/32-settings-ai-agents.png)

### Supported AI Coding Agents

WorktreeWise provides presets and icon support for 7 AI coding assistants:

| Agent | CLI Executable | Installation Command | Prerequisites |
| :--- | :--- | :--- | :--- |
| **Claude Code** | `claude` | `npm install -g @anthropic-ai/claude-code` | Node.js 18+ |
| **Codex** | `codex` | `npm install -g @openai/codex` | Node.js 18+ |
| **Cursor CLI** | `cursor-agent` | `irm 'https://cursor.com/install?win32=true' \| iex` (PowerShell) | Cursor installation |
| **Antigravity CLI** | `agy` | `irm https://antigravity.google/cli/install.ps1 \| iex` (PowerShell) | Antigravity suite |
| **Qwen Code** | `qwen` | `npm install -g @qwen-code/qwen-code@latest` | Node.js 22+ |
| **Kimi Code** | `kimi` | `npm install -g @moonshot-ai/kimi-code` | Node.js 22.19+ |
| **OpenCode** | `opencode` | `npm install -g opencode-ai` | Node.js 18+ |

### Configure and Test Agents

- **Enable / Disable**: Toggle the switch on each card to show or hide the agent in terminal panes.
- **Custom Paths & Flags**: Select the pencil icon to specify a custom binary path or default command-line flags (such as model flags or temperature parameters).
- **Run Diagnostics**: Select **Test** on any agent card to run a sandbox check. WorktreeWise executes the binary and outputs stdout/stderr so you can verify authentication and executable permissions before launching real tasks.

## Shell Settings

The **Shell** tab specifies which command-line shell is launched inside embedded terminal panes.

![Shell settings](/images/releases/1.1.0/33-settings-shell.png)

### Shell Detection & Selection

WorktreeWise automatically discovers installed shells across standard platform paths:
- **Windows**: PowerShell (`pwsh`), Windows PowerShell (`powershell`), Command Prompt (`cmd`), Git Bash (`git-bash`), WSL (`wsl`).
- **macOS & Linux**: Zsh (`zsh`), Bash (`bash`), Fish (`fish`), Nushell (`nu`), POSIX Shell (`sh`).

Select any detected shell card to designate it as the default shell for all new embedded terminal sessions.

### Custom Shell Path

To use a custom shell binary:
1. Enter the absolute path in the **Custom shell path** input field.
2. Select the folder icon to browse the filesystem if needed.
3. Select **Apply** to activate the custom shell.

## Git Settings

The **Git** tab configures the path to the Git binary used for worktree operations, log queries, branch listings, and diffs.

![Git settings](/images/releases/1.1.0/34-settings-git.png)

### Git Executable Path

By default, WorktreeWise uses the `git` executable found in your system `PATH`. To target a specific Git installation:

- **Windows**: `C:\Program Files\Git\bin\git.exe`
- **macOS / Linux**: `/usr/bin/git` or `/usr/local/bin/git`

Enter the path and select **Apply** to save.

## Encoding Settings

The **Encoding** tab specifies the character encoding used when reading Git command output and commit logs.

![Encoding settings](/images/releases/1.1.0/35-settings-encoding.png)

### Supported Character Encodings

Select your preferred encoding from the dropdown (default is **UTF-8**):

| Category | Encodings |
| :--- | :--- |
| **Unicode** | UTF-8, UTF-16, UTF-32 |
| **Western & European** | ASCII, ISO-8859-1 through ISO-8859-16, Windows-1250 through Windows-1258, CP437, CP850, CP852, CP865, CP866 |
| **East Asian** | Shift JIS, EUC-JP, ISO-2022-JP, GB2312, GBK, GB18030, Big5, ISO-2022-CN, ISO-2022-KR |
| **Cyrillic** | KOI8-R, KOI8-U, MacCyrillic |
| **Other** | TIS-620, VISCII, MacRoman |
