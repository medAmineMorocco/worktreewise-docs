## Introduction

<Callout type="info">
    WorktreeWise is a **UI-based Git worktree manager** that simplifies creating, managing, and automating Git worktrees.
</Callout>

### Key Features
✔️ **Full UI Control** – No terminal needed for managing worktrees

✔️ **Pre/Post Hooks** – Automate setup processes for new worktrees

✔️ **IDE & Terminal Integration** – Open worktrees directly in editors and terminals

✔️ **Workflows** – Automate command execution across multiple worktrees

✔️ **Git Log & Diff** – Visualize history and compare worktrees, branches, or commits
