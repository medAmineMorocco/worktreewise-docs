## 1. Repository & Worktree Overview Dashboard

The Overview dashboard provides central visibility into all active worktrees without manual terminal queries:

- **6 Summary Metrics**: Monitor Total Worktrees, Clean Worktrees, Dirty Worktrees, Ahead/Behind divergence, Total Disk Footprint, and Stale References.
- **Clean / Dirty Donut Chart**: Visual distribution of uncommitted working tree states across the repository.
- **Worktree Inspector**: Select any worktree to view commit details, upstream sync status, and large untracked file alerts.
- **4-Way Storage Breakdown**: Categorizes disk usage into Project Files, Git metadata, Dependencies (`node_modules`), and Build artifacts.

👉 [Learn more in the Worktree Overview Guide](/1.1/git-worktrees/overview)

---

## 2. Advanced Worktree Creation Wizard

The worktree creation modal includes built-in isolation and optimization tools:

- **4 Creation Modes**: Create from `HEAD`, existing local/remote tracking branches, Git release tags, or specific commits from Git Log.
- **Sparse Checkout**: Select specific subdirectories to checkout with byte size estimates, reducing disk usage and index times in large monorepos.
- **Shared Dependencies**: Symlink `node_modules` from your primary worktree to eliminate redundant package installs.
- **Environment Isolation**: Detect `.env` configurations and apply Shared, Suffix, or Auto-Port strategies to avoid port collisions and database conflicts.
- **Pre- and Post-Hooks**: Configure shell commands to run automatically before or after worktree provisioning.

👉 [Learn more in the Worktree Creation Guide](/1.1/git-worktrees/create)

---

## 3. Multi-Pane Terminal & AI Agent Workspace

Run shell sessions and autonomous coding agents side by side in worktree-scoped panes:

- **Flexible Tiling**: Arrange panes in 1, 2, or 3 columns, or use Auto layout to adapt to window dimensions.
- **7 Supported AI Agents**: Built-in detection and configuration presets for Claude Code, OpenAI Codex, Cursor CLI, Google Antigravity, Qwen Code, Kimi CLI, and OpenCode.
- **Smart Context**: Attach active branch context, latest commit metadata, worktree directory paths, and file change statuses to agent prompts.
- **Sidebar Status Indicators**: Glowing robot indicators highlight which worktrees have actively running agents or terminal processes.

👉 [Learn more in the AI Agents Guide](/1.1/integrations/ai-agents) and [Terminal Guide](/1.1/integrations/terminal)

---

## 4. Reusable Automation Workflows

Automate command execution across multiple worktrees with process controls:

- **Sequential & Parallel Modes**: Run command chains across worktrees one at a time, or execute them concurrently with worker threads.
- **PTY Execution Engine**: Commands run in pseudo-terminals with ANSI colors, progress spinners, and interactive prompt safeguards.
- **Import & Export**: Import workflow definitions from `.git/WorktreeWise/` across repositories with conflict validation.
- **Process Controls**: Live execution logs with full-screen expansion (`Shift + F`) and graceful termination (`Esc`).

👉 [Learn more in the Workflows Guide](/1.1/workflows)

---

## 5. Privacy-Focused Git Log & Pairwise Git Diff

- **Column Visibility Toggles**: Show or hide Author, Date, SHA, and Refs columns for clean screen recordings and privacy compliance.
- **Inline Commit Authoring**: Stage and unstage files, review per-file diffs, write commit messages, and amend previous commits.
- **4-Way Pairwise Diff**: Compare any two worktrees, branches, tags, or commits side by side or line by line.

👉 [Learn more in the Git Log Guide](/1.1/git-operations/log) and [Git Diff Guide](/1.1/git-operations/diff)

---

## 6. Review-First Worktree Pruning

Replace destructive CLI pruning with an audited cleanup workflow:

- **Dry-Run Inspection**: Previews invalid worktree records without altering Git metadata.
- **Selective Checkbox Cleanup**: Select exactly which stale references to prune while preserving worktrees on unmounted drives.

👉 [Learn more in the Pruning Guide](/1.1/git-worktrees/prune)

---

## Upgrading to 1.1.0

WorktreeWise 1.1.0 is fully backward-compatible with repositories created in earlier versions. Existing worktrees, Git branches, and settings are detected automatically upon launching the updated application.
