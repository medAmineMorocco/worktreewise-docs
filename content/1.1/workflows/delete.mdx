# Delete a Workflow

When a workflow definition is no longer needed, you can delete it to keep your repository workflow library clean. Deleting a workflow removes only the automation recipe and has no impact on worktree files, Git branches, or project dependencies.

---

## How to Delete a Workflow

1. In the **Workflows** view, locate the workflow in the Saved Workflows table.
2. In the Actions column, select the **Red Trash icon (🗑️)**.
3. A confirmation prompt appears asking:
   > *"Are you sure you want to delete this workflow?"*
4. Select **Confirm** to permanently remove the definition from `.git/WorktreeWise/`.

<Callout type="warning">
Deleting a workflow definition is permanent. If you might need the command sequence in the future, select **Duplicate** first to create an archived copy.
</Callout>

---

## What Happens to Your Worktrees

Deleting a workflow removes only the automation recipe:

- **Filesystem Intact**: No source files, dependencies, build artifacts, or directories inside your worktrees are touched.
- **Git Branches Intact**: Git branches, commits, stashes, and tags remain completely unaltered.
- **Execution Log Preserved**: The active Execution Log panel retains previously captured command outputs until explicitly restarted.
