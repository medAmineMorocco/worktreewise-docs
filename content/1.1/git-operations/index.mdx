# Git Operations

WorktreeWise integrates essential Git tools directly into your desktop environment. Inspect branching history across linked checkouts, stage and author atomic commits per worktree, and evaluate code divergence using visual side-by-side or line-by-line comparisons.

## Tool Summary & Highlights

| Feature | Key Capabilities | Primary Shortcut |
| :--- | :--- | :--- |
| **[Git Log](/1.1/git-operations/log)** | Interactive commit graph, per-worktree scoping, author filtering, column visibility toggles (Author, Date, SHA, Refs), real-time working tree status, inline staging/unstaging, discard changes. | `Shift + G` |
| **[Create a Commit](/1.1/git-operations/commit)** | Working tree staging drawer, 72-character summary validation, multi-line descriptions, commit amending, and reviewed file tracking. | Open via Git Log |
| **[Git Diff](/1.1/git-operations/diff)** | 4-way pairwise comparison matrix (Worktree, Branch, Tag, Commit), side-by-side dual pane or unified line-by-line diffs, word-level difference highlighting, and interactive file navigation. | `Shift + D` |

## Worktree-Aware Git Advantages

1. **Per-Worktree Scope**: Unlike standard Git GUI clients that monitor only one working directory at a time, WorktreeWise lets you switch context between linked worktrees instantly without opening separate windows.
2. **Privacy Controls**: Hide author names and commit SHAs with a single click to prepare clean, anonymized screenshots or product screencasts without exposing contributor identities.
3. **Integrated Staging**: Inspect working tree files and stage, unstage, or discard changes directly without launching an external terminal or heavy IDE.
