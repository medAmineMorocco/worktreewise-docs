# Workspace Integrations

WorktreeWise acts as the central mission control for your development workspace. By deeply integrating with your local shell environments, external code editors, and cutting-edge autonomous AI coding agents, WorktreeWise transforms isolated Git worktrees into ready-to-code environments.

## Integrations Feature Matrix

| Integration Domain | Supported Tools | Key Capabilities |
| :--- | :--- | :--- |
| **[AI Agents](/integrations/ai-agents)** | Claude Code, OpenAI Codex, Cursor CLI (`cursor-agent`), Antigravity (`agy`), Qwen Code, Kimi CLI, OpenCode | Multi-pane tiling, Smart Context prompt generation (worktree path, branch, latest commit, dirty status), real-time activity indicators in the sidebar, and process management. |
| **[Embedded Terminal](/integrations/terminal)** | PowerShell, Git Bash, WSL (`wsl.exe`), Bash, Zsh, Fish, Nushell (`nu`), Command Prompt | XTerm.js hardware-accelerated canvas, truecolor support, 1/2/3 pane layouts, toggle between standard Terminal and AI Agent modes with a single click. |
| **[Editor Detection](/settings#editor-configuration)** | VS Code, Cursor, Windsurf, WebStorm, IntelliJ IDEA, PyCharm, GoLand, RustRover, CLion, Rider, PhpStorm, Zed, Sublime | One-click auto-detection (`editors:detect-all`), custom path overrides, launch worktrees with preserved editor configurations, plugins, and bookmarks. |
| **[Shell Environments](/settings#shell-configuration)** | Windows, macOS, Linux native shells | Configurable shell binary paths, environment sanitization for Node.js/Electron processes, and automatic working directory resolution per worktree. |
