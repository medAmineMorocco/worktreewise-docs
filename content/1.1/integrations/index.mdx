# Workspace Integrations

WorktreeWise connects isolated Git worktrees directly to your developer tooling. Launch worktrees into external IDEs with preserved configurations, execute commands inside embedded multi-pane terminals, or run autonomous AI coding agents side by side with repository context.

## Integrations Feature Matrix

| Integration Domain | Supported Tools | Key Capabilities |
| :--- | :--- | :--- |
| **[Embedded Terminal](/1.1/integrations/terminal)** | PowerShell, Git Bash, WSL, Bash, Zsh, Fish, Nushell, Command Prompt | XTerm.js hardware acceleration, truecolor support, 1/2/3 column layouts, toggle between standard Terminal and AI Agent modes. |
| **[AI Agents](/1.1/integrations/ai-agents)** | Claude Code, OpenAI Codex, Cursor CLI (`cursor-agent`), Antigravity (`agy`), Qwen Code, Kimi CLI, OpenCode | Multi-pane tiling, Smart Context prompt generation (worktree path, branch, latest commit, dirty status), real-time activity indicators in the sidebar, process management. |
| **[External IDEs](/1.1/integrations/ide)** | VS Code, Cursor, Windsurf, WebStorm, IntelliJ IDEA, PyCharm, GoLand, RustRover, CLion, Rider, PhpStorm, Zed, Sublime | One-click auto-detection (`Scan`), custom executable path overrides, launch worktrees with preserved IDE configurations, plugins, and bookmarks. |
| **[JetBrains Plugin](/1.1/integrations/jetbrains-plugin)** | All modern JetBrains IDEs (PRO / PRO PLUS license) | Switch worktrees from the IDE menu without opening the desktop app; open current project in WorktreeWise; preserve bookmarks and run configurations. |
| **[Shell Environments](/1.1/settings#shell-settings)** | Windows, macOS, Linux native shells | Configurable shell binary paths, environment sanitization for Node.js/Electron processes, automatic worktree working directory resolution. |
