## Edit a Workflow


To edit an existing workflow:

        1. Go to the **Workflows** section.
        2. Locate the workflow you want to edit and click the **Edit Workflow** button.
        3. Modify the workflow name or update the commands.
        4. Click **Save** to apply the changes.
