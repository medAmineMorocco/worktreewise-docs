## Import a Workflow

To import an existing workflow from another repository:

        1. Navigate to the **Workflow** section.
        2. Click on the **Import Workflow** button.
        3. Select the repository containing the workflows.
        4. Choose the workflows to import.
        5. Click **Confirm** to add them into the current repository.
