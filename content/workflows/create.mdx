## Create a Workflow

To create a new workflow:

        1. Navigate to the **Workflows** section.
        2. Click on the **Add Workflow** button.
        3. Enter a name for the workflow.
        4. Define the commands to be executed within the workflow.
        6. Click **Save** to store the workflow.
