# Managing Git Worktrees in WorktreeWise

Git worktrees allow you to work with multiple branches simultaneously without needing separate clones of your repository. WorktreeWise simplifies this process by providing an intuitive way to manage your worktrees.

## What You Can Do

With WorktreeWise, you can:

✅ **Create** new worktrees for different branches  
✅ **Rename** worktrees to keep things organized  
✅ **Move** worktrees to a new location  
✅ **Delete** worktrees you no longer need  
✅ **Lock & Unlock** worktrees to prevent accidental changes
