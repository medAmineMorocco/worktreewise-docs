## List Git Worktrees

The Worktrees panel shows all the Git worktrees linked to your current repository — including the total number of worktrees.

![Move a Git Worktree](/images/content/git-worktrees/list/list-worktrees.png)

This view helps you quickly navigate between worktrees, open them in your editor or terminal, and perform common actions like renaming, locking, unlocking, or deleting.

![Move a Git Worktree](/images/content/git-worktrees/list/list-worktrees-actions.png)
