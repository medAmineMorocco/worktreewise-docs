## Lock a Git Worktree

To prevent modifications to a worktree:

1. Navigate to the **Worktrees** section.
2. Find the worktree you want to lock.
3. Click the **Lock** button.

![Lock Worktree](/images/content/git-worktrees/lock/lock-worktree.png)

The worktree will be marked as locked, preventing changes.

![Worktree Locked](/images/content/git-worktrees/lock/worktree-locked.png)
