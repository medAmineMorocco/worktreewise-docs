# Unlock a Git Worktree

To unlock a worktree:

1. Navigate to the **Worktrees** section.
2. Find the locked worktree.
3. Click the **Unlock** button.

![Unlock Worktree](/images/content/git-worktrees/unlock/unlock-worktree.png)


The worktree will now be editable again.

![Worktree Unlocked](/images/content/git-worktrees/unlock/worktree-unlocked.png)
