# Setting Up Shell in WorktreeWise

WorktreeWise allows you to configure your preferred shell to open worktrees in the terminal.

## How to Set Up a Shell

1. Open **WorktreeWise Settings**.
2. Navigate to the **Shell Configuration** section.
3. Enter the full path to your preferred shell:
- **Windows**: `C:\Windows\System32\WindowsPowerShell\v1.0\powershell.exe`
- **macOS**: `/bin/zsh` or `/bin/bash`
- **Linux**: `/bin/bash`, `/bin/zsh`, or any preferred shell path.
4. Click **Save Settings**.
5. Restart WorktreeWise to apply the changes.

## Verifying Your Shell Setup

1. Open a worktree in the terminal.
2. Check that the correct shell launches.
3. If an error occurs, verify the path and ensure the shell is installed on your system.

<Callout type="info">For Windows users, ensure that PowerShell or Git Bash is installed and accessible from the system path.</Callout>


# Open Worktree in Terminal

WorktreeWise allows you to quickly open a worktree in your terminal for efficient command-line operations.

## How to Open a Worktree in Terminal

### Method 1: Using the UI

1. Locate the worktree in the WorktreeWise interface.
2. Click on the **Terminal** icon next to the worktree.
3. The terminal will open in the selected worktree’s directory.

### Method 2: Using a Keyboard Shortcut

- Press **Shift + Enter** while selecting a worktree to open it in the terminal instantly.

<Callout type="info">Ensure your system has a default terminal configured to open from external applications.</Callout>
