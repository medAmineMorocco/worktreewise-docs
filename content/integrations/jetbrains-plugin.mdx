# WorktreeWise for JetBrains Plugin

The **WorktreeWise for JetBrains** plugin allows you to switch Git worktrees directly from inside your JetBrains IDE. It integrates with your active WorktreeWise project and preserves IDE-specific context—including bookmarks and run/debug configurations—when switching between branches.

<Callout type="info">
The JetBrains plugin provides in-editor switching actions. Advanced worktree management—such as sparse checkouts, automation workflows, diffs, and pruning—is performed inside the WorktreeWise desktop application.
</Callout>

---

## Requirements

Before installing the plugin, verify that your environment meets the following requirements:

| Requirement | Specification |
| :--- | :--- |
| **WorktreeWise Desktop App** | Installed on your machine and activated. |
| **License Tier** | Active **PRO** or **PRO PLUS** license. |
| **Compatible IDEs** | IntelliJ IDEA, WebStorm, PyCharm, GoLand, CLion, Rider, PhpStorm, RubyMine, or Android Studio. |

---

## Installation

Install the plugin directly from the JetBrains Marketplace:

1. In your JetBrains IDE, open **Settings / Preferences → Plugins**.
2. Select the **Marketplace** tab.
3. Search for **WorktreeWise**.
4. Select **Install**.
5. Restart your IDE if prompted.

Once installed, WorktreeWise actions are automatically registered in the main application menu.

---

## Available Actions

The plugin provides two primary actions accessible from the IDE menu:

![WorktreeWise for Jetbrains Plugin](/images/content/integrations/jetbrains/worktreewise-for-jetbrains-plugin.png)

### 1. Switch Worktree

Switch between active Git worktrees without leaving the editor:

- Lists all registered worktrees for the current repository.
- Opens the selected worktree directly in the current or new IDE window.
- Preserves your bookmarks, active run/debug profiles, and project settings.

![Switch Worktree Action](/images/content/integrations/jetbrains/switch-worktree-action.png)

### 2. Open Project in WorktreeWise

Send the current project path to the WorktreeWise desktop app:

- Opens the active repository in a WorktreeWise tab.
- Allows you to perform advanced management tasks: create worktrees with sparse checkout, run multi-worktree workflows, inspect Git logs, or prune stale checkouts.

## Preserved Context Across Worktrees

Standard Git worktree CLI workflows treat each worktree folder as an isolated project, requiring developers to reconfigure IDE settings for every branch. The WorktreeWise plugin preserves development context:

| Context Element | Standard Worktree CLI | WorktreeWise for JetBrains |
| :--- | :--- | :--- |
| **Switch Worktrees** | Supported | Supported |
| **Bookmarks** | Lost | **Preserved** |
| **Run / Debug Configurations** | Lost | **Preserved** |
| **Shared IDE Tooling** | Lost | **Preserved** |
| **Desktop App Synchronization** | None | **Full Bidirectional Sync** |

## Custom Keyboard Shortcuts

To assign custom shortcuts to plugin actions in your JetBrains IDE:

1. Open **Settings / Preferences → Keymap**.
2. Search for **WorktreeWise**.
3. Right-click **Switch Worktree** or **Open Project in WorktreeWise** and select **Add Keyboard Shortcut**.
4. Press your desired key combination and select **OK**.
