## Setting Up Shell in WorktreeWise

WorktreeWise allows you to configure your preferred shell that will be used when opening a terminal inside a worktree.

---
### 1. Opening Shell Settings

To access the **Shell** settings:

1. Open the **Settings** window by clicking on **File → Settings** or using the shortcut **Shift + S**.
2. In the sidebar, select the **Shell** tab.
---

### 2. Configure the Default Shell

- In the **Default Shell** field, enter the full path to the shell executable you want WorktreeWise to use.
- Once you **quit the tab**, the changes are automatically saved.
- WorktreeWise will then use this shell whenever you open a terminal in a worktree.

<Callout type="warning">The dialog provides examples of paths for **known shells** depending on your operating system</Callout>

<Callout type="warning">If no shell path is configured, WorktreeWise will attempt to use your system’s default shell.</Callout>

![Configure the Full Path of a Shell](/images/content/integrations/terminal/configure-shell.png)

## Open Worktree in Terminal

WorktreeWise allows you to quickly open a worktree in your terminal for efficient command-line operations.

1. Locate the worktree you want to open.
2. Click on the **Open in Terminal** option.
3. The terminal will open in the selected worktree’s directory.
