# Open a Worktree in an IDE

WorktreeWise integrates with modern code editors and IDEs, allowing you to launch any worktree into your development environment with a single click. When opening a worktree, WorktreeWise preserves editor configurations, run/debug profiles, and bookmarks inherited from your primary project.

---

## How to Open a Worktree in an IDE

1. In the **Worktrees** panel, locate the target worktree.
2. Select the three-dot **Actions** menu and hover over **Open in**.
3. Select your desired editor (for example, **VS Code**, **Cursor**, **WebStorm**, or **IntelliJ IDEA**).
4. The editor launches with its workspace set to the worktree directory.

![Editor choices](/images/releases/1.1.0/17-worktree-actions-editors.png)

<Callout type="info">
If your preferred editor does not appear in the menu, ensure it is enabled in [Settings → Editors](/settings#editors-settings).
</Callout>

---

## Configuring Editors in Settings

To configure which editors appear in the **Open in** menu:

1. Open **Settings** (`Shift + S`) and select the **Editors** tab.
2. Select **Scan** to automatically discover installed IDEs on your machine (`editors:detect-all`).
3. Click any editor card to toggle its enabled state:
   - **Enabled**: Displays a highlighted blue border and appears in worktree action menus.
   - **Disabled**: Excluded from menus to keep the interface focused.

![Editor settings](/images/releases/1.1.0/31-settings-editors.png)

### Custom Executable Paths

If an editor is installed in a portable directory or custom path:

1. Select the **Pencil icon (✏️)** on the editor card.
2. Enter the absolute path to the executable file.
3. Select **Edit** to save.

![Edit the Full Path of an editor](/images/releases/1.1.0/configure-editor-path.png)

<Callout type="tip">
The editor configuration modal provides example executable paths for Windows, macOS, and Linux. For a complete list of standard installation paths, see [Editors Settings Reference](/settings#editors-settings).
</Callout>

## Preserved IDE Configurations

When you open a worktree through WorktreeWise, your IDE automatically inherits configurations established in your primary worktree. You do not need to reconfigure settings for each new branch:

| Preserved Element | Details |
| :--- | :--- |
| **Bookmarks** | Code line bookmarks and contextual tags are retained. |
| **Run / Debug Configurations** | Saved run targets, build profiles, and debugger launch arguments remain available. |
| **Scripts and Tools** | External build tools, file watchers, and custom IDE actions are preserved. |
| **Version Control Settings** | Project VCS mappings and changelist preferences remain intact. |
| **Recent Files & History** | Local file history and recent search queries carry over. |
