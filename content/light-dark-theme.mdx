# Switch Light and Dark Mode

WorktreeWise includes high-contrast light and dark themes designed for code readability and visual comfort. The active theme synchronizes across the entire application interface, including embedded XTerm.js terminal panes, Git diff viewers, and commit graphs.

---

## Switch Theme Using a Keyboard Shortcut

Press the global shortcut anywhere within the application to toggle immediately between light and dark mode:

- **Shortcut**: `Shift + T`

---

## Switch Theme from the Application Menu

1. Open the application menu and select **View**.
2. Select **Switch Theme**.
3. The interface toggles immediately between light and dark modes.
