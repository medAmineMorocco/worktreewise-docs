## Switching Light and Dark Mode

WorktreeWise provides both light and dark themes for an optimal user experience.

You can switch between light and dark mode using one of the following methods:

### Method 1: Using the Menu Button

1. Click on **View** in the menu.
2. Select the **Switch Theme** option.
3. The theme will instantly switch between light and dark mode.

![WorktreeWise in light mode](/images/releases/1.1.0/46-light-mode.png)

### Method 2: Using a Keyboard Shortcut

- Press **Shift + T** to toggle between light and dark mode instantly.

![WorktreeWise in dark mode](/images/releases/1.1.0/45-dark-mode.png)

<Callout type="info">The selected theme is saved and applied automatically on the next launch.</Callout>
